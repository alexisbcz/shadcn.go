## Installation

```bash
go get github.com/alexisbcz/components
go mod tidy
```

The component's behavior is a JavaScript module served by the runtime. Serve
the runtime and load it once per page, as in the
[components README](https://github.com/alexisbcz/components#use):

```go showLineNumbers
http.Handle(runtime.Prefix, runtime.Handler())
// In <head>:
runtime.Scripts(r)
```

## Usage

```go showLineNumbers
import (
	"github.com/alexisbcz/components/ui/avatar"
	h "github.com/alexisbcz/libhtml"
)
```

```go showLineNumbers
avatar.Avatar(
	avatar.Image(h.Src("https://github.com/shadcn.png")),
	avatar.Fallback("CN"),
)
```

## Composition

Use the following composition to build an `avatar.Avatar`:

```text
avatar.Avatar
├── avatar.Image
├── avatar.Fallback
└── avatar.Badge
```

Use the following composition to build an `avatar.Group`:

```text
avatar.Group
├── avatar.Avatar
│   ├── avatar.Image
│   ├── avatar.Fallback
│   └── avatar.Badge
├── avatar.Avatar
│   ├── avatar.Image
│   ├── avatar.Fallback
│   └── avatar.Badge
└── avatar.GroupCount
```

## Badge

Use `avatar.Badge` to add a badge to the avatar. The badge is positioned at the bottom right of the avatar.

<ComponentPreview styleName="radix-nova" name="avatar-badge" />

Pass `h.Class` to add custom styles to the badge such as custom colors, sizes, etc.

```go showLineNumbers
avatar.Avatar(
	avatar.Image(h.Src("https://github.com/shadcn.png"), h.Alt("@shadcn")),
	avatar.Fallback("CN"),
	avatar.Badge(h.Class("bg-green-600 dark:bg-green-800")),
)
```

## API Reference

| Function | Options |
| --- | --- |
| `avatar.Avatar` | `avatar.SizeDefault` (default), `avatar.SizeSm`, `avatar.SizeLg` |
| `avatar.Image` | `h.Src`, `h.Alt` (and `h.CrossOrigin` or `h.Attr("referrerpolicy", ...)`, which also apply to the loading request); shown once the image has loaded |
| `avatar.Fallback` | `avatar.DelayMs(ms)` to delay rendering the fallback; shown while the image has not loaded |
| `avatar.Badge` | none; a badge indicator, positioned at the bottom right |
| `avatar.Group` | none; a group of overlapping avatars |
| `avatar.GroupCount` | none; a count indicator in an avatar group |

Other children are HTML attributes (`h.Class`, `h.ID`, ...) and content.

When the image's loading status changes, the avatar dispatches a
`shadcn:loading-status-change` DOM event with `detail.status` set to
`"loading"`, `"loaded"` or `"error"` (Radix `onLoadingStatusChange`):

```js showLineNumbers
avatarEl.addEventListener("shadcn:loading-status-change", (event) => {
  console.log(event.detail.status)
})
```

The behavior follows [Radix UI's Avatar](https://www.radix-ui.com/primitives/docs/components/avatar#api-reference).
