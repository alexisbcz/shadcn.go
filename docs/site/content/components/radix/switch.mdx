## Installation

```bash
go get github.com/alexisbcz/components
go mod tidy
```

The component's behavior is a JavaScript module served by the runtime. Serve
the runtime and load it once per page, as in the
[components README](https://github.com/alexisbcz/components#use):

```go showLineNumbers
http.Handle(runtime.Prefix, runtime.Handler())
// In <head>:
runtime.Scripts(r)
```

## Usage

```go showLineNumbers
import (
	switchui "github.com/alexisbcz/components/ui/switch"
	h "github.com/alexisbcz/libhtml"
)
```

```go showLineNumbers
switchui.Switch()
```

Pass `h.Disabled()` to `switchui.Switch` to disable the switch. Pass `h.Data("disabled", "true")` to `field.Field` for styling.

Pass `h.Aria("invalid", "true")` to `switchui.Switch` to indicate an invalid state. Pass `h.Data("invalid", "true")` to `field.Field` for styling.

## API Reference

| Function | Options |
| --- | --- |
| `switchui.Switch` | `switchui.Checked(bool)` for the initial state, `switchui.SizeDefault` or `switchui.SizeSm`, `switchui.Name("...")`, `switchui.Value("...")` (default `"on"`), `switchui.Required(bool)`, `switchui.Disabled(bool)`, `switchui.Form("form-id")` |

Other children are HTML attributes (`h.ID`, `h.Class`, `h.Aria`, ...). Inside a
`<form>`, the switch renders a hidden checkbox input, so it submits with the
form.

Before every change, the switch dispatches a cancelable `shadcn:checked-change`
event with `detail: { checked }`. Cancel it to keep the current state.

```js showLineNumbers
button.addEventListener("shadcn:checked-change", (e) => {
  console.log(e.detail.checked)
})
```

The behavior follows [Radix UI's Switch](https://www.radix-ui.com/docs/primitives/components/switch#api-reference).
