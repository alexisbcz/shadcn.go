## Installation

```bash
go get github.com/alexisbcz/components
go mod tidy
```

The component's behavior is a JavaScript module served by the runtime. Serve
the runtime and load it once per page, as in the
[components README](https://github.com/alexisbcz/components#use):

```go showLineNumbers
http.Handle(runtime.Prefix, runtime.Handler())
// In <head>:
runtime.Scripts(r)
```

## Usage

```go showLineNumbers
import (
	"github.com/alexisbcz/components/ui/accordion"
	h "github.com/alexisbcz/libhtml"
)
```

```go showLineNumbers
accordion.Accordion(accordion.TypeSingle, accordion.Collapsible(true), accordion.Value("item-1"),
	accordion.Item(accordion.Value("item-1"),
		accordion.Trigger("Is it accessible?"),
		accordion.Content("Yes. It adheres to the WAI-ARIA design pattern."),
	),
)
```

## Composition

Use the following composition to build an `Accordion`:

```text
accordion.Accordion
├── accordion.Item
│   ├── accordion.Trigger
│   └── accordion.Content
└── accordion.Item
    ├── accordion.Trigger
    └── accordion.Content
```

## API Reference

| Function | Options |
| --- | --- |
| `accordion.Accordion` | `accordion.TypeSingle` (default) or `accordion.TypeMultiple`, `accordion.Collapsible(bool)`, `accordion.Value(v)` (initially open item; repeat for several), `accordion.Disabled(bool)`, `accordion.OrientationVertical` (default) or `accordion.OrientationHorizontal`, `accordion.DirLTR` or `accordion.DirRTL` |
| `accordion.Item` | `accordion.Value(v)`, `accordion.Disabled(bool)` |
| `accordion.Trigger` | none |
| `accordion.Content` | none; its classes style the inner `<div>` |

Other children are HTML attributes (`h.Class`, `h.ID`, ...) and content.

Before every change, the root dispatches a cancelable `shadcn:value-change`
event. Its `detail.value` is a string for a single accordion and an array for
a multiple one:

```js showLineNumbers
document.querySelector("#faq").addEventListener("shadcn:value-change", (e) => {
  console.log(e.detail.value)
})
```

The behavior follows [Radix UI's Accordion](https://www.radix-ui.com/primitives/docs/components/accordion#api-reference).
