## Installation

```bash
go get github.com/alexisbcz/components
go mod tidy
```

## Usage

```go showLineNumbers
import (
	aspectratio "github.com/alexisbcz/components/ui/aspect-ratio"
	h "github.com/alexisbcz/libhtml"
)
```

```go showLineNumbers
aspectratio.AspectRatio(aspectratio.Ratio(16.0/9),
	h.Img(h.Src("..."), h.Alt("Image"), h.Class("rounded-md object-cover")),
)
```

## API Reference

| Function | Options |
| --- | --- |
| `aspectratio.AspectRatio` | `aspectratio.Ratio(width / height)` (default 1) |

Other children are HTML attributes (`h.Class`, `h.ID`, ...) and content. They
go to the inner `<div>`, which is absolutely positioned inside a wrapper sized
to the ratio.

For more information, see the [Radix UI documentation](https://www.radix-ui.com/primitives/docs/components/aspect-ratio#api-reference).
