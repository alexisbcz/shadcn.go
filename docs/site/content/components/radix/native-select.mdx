## Installation

```bash
go get github.com/alexisbcz/components
go mod tidy
```

## Usage

```go showLineNumbers
import (
	nativeselect "github.com/alexisbcz/components/ui/native-select"
	h "github.com/alexisbcz/libhtml"
)
```

```go showLineNumbers
nativeselect.NativeSelect(
	nativeselect.Option(h.Value(""), "Select a fruit"),
	nativeselect.Option(h.Value("apple"), "Apple"),
	nativeselect.Option(h.Value("banana"), "Banana"),
	nativeselect.Option(h.Value("blueberry"), "Blueberry"),
	nativeselect.Option(h.Value("pineapple"), "Pineapple"),
)
```

## Composition

### Simple

Options placed directly under `nativeselect.NativeSelect` (no `nativeselect.OptGroup`).

```text
nativeselect.NativeSelect
├── nativeselect.Option
├── nativeselect.Option
├── nativeselect.Option
└── nativeselect.Option
```

### With groups

Use `nativeselect.OptGroup` to organize options into categories.

```text
nativeselect.NativeSelect
├── nativeselect.OptGroup
│   ├── nativeselect.Option
│   └── nativeselect.Option
└── nativeselect.OptGroup
    ├── nativeselect.Option
    └── nativeselect.Option
```

## Groups

Use `nativeselect.OptGroup` to organize options into categories. Set its label with `h.LabelAttr`.

## Native Select vs Select

- Use `nativeselect.NativeSelect` for native browser behavior, better performance, or mobile-optimized dropdowns.
- Use `selectui.Select` for custom styling, animations, or complex interactions.

## API Reference

| Function | Options |
| --- | --- |
| `nativeselect.NativeSelect` | `nativeselect.SizeDefault`, `nativeselect.SizeSm`; builder methods `.Name`, `.Form`, `.Disabled`, `.Required`, `.Multiple`, `.AutoFocus` |
| `nativeselect.Option` | `h.Value(v)`, `h.Disabled()` |
| `nativeselect.OptGroup` | `h.LabelAttr(label)`, `h.Disabled()` |

Other children are HTML attributes (`h.Class`, `h.ID`, ...) and content.
Attributes given to `nativeselect.NativeSelect` go to the `<select>`.

```go showLineNumbers
nativeselect.NativeSelect(
	nativeselect.OptGroup(h.LabelAttr("Fruits"),
		nativeselect.Option(h.Value("apple"), "Apple"),
		nativeselect.Option(h.Value("banana"), "Banana"),
	),
).Name("fruit")
```
