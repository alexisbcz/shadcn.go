```bash
go get github.com/alexisbcz/components
go mod tidy
```

## Usage

```go showLineNumbers
import (
	"github.com/alexisbcz/components/ui/separator"
	h "github.com/alexisbcz/libhtml"
)
```

```go showLineNumbers
separator.Separator()
```

## API Reference

| Function | Options |
| --- | --- |
| `separator.Separator` | `separator.Horizontal` (default) or `separator.Vertical`, `separator.Decorative(bool)` (default true: `role="none"`; false renders `role="separator"`) |

Other children are HTML attributes (`h.Class`, `h.ID`, ...). The behavior
follows [Radix UI's Separator](https://www.radix-ui.com/docs/primitives/components/separator#api-reference).
