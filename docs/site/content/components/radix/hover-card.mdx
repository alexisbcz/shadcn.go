## Installation

```bash
go get github.com/alexisbcz/components
go mod tidy
```

The component's behavior is a JavaScript module served by the runtime. Serve
the runtime and load it once per page, as in the
[components README](https://github.com/alexisbcz/components#use):

```go showLineNumbers
http.Handle(runtime.Prefix, runtime.Handler())
// In <head>:
runtime.Scripts(r)
```

## Usage

```go showLineNumbers
import (
	hovercard "github.com/alexisbcz/components/ui/hover-card"
	h "github.com/alexisbcz/libhtml"
)
```

```go showLineNumbers
hovercard.HoverCard(
	hovercard.Trigger("Hover"),
	hovercard.Content("The React Framework – created and maintained by @vercel."),
)
```

## Composition

Use the following composition to build a `HoverCard`:

```text
hovercard.HoverCard
├── hovercard.Trigger
└── hovercard.Content
```

## Trigger Delays

Pass `hovercard.OpenDelay` and `hovercard.CloseDelay` (in milliseconds) to
`hovercard.HoverCard` to control when the card opens and closes. The defaults
are 700 and 300.

```go showLineNumbers
hovercard.HoverCard(hovercard.OpenDelay(100), hovercard.CloseDelay(200),
	hovercard.Trigger("Hover"),
	hovercard.Content("Content"),
)
```

## Positioning

Pass a side (`hovercard.SideTop`, `SideRight`, `SideBottom`, `SideLeft`) and an
alignment (`hovercard.AlignStart`, `AlignCenter`, `AlignEnd`) to
`hovercard.Content` to control placement.

```go showLineNumbers
hovercard.HoverCard(
	hovercard.Trigger("Hover"),
	hovercard.Content(hovercard.SideTop, hovercard.AlignStart, "Content"),
)
```

## API Reference

| Function | Options |
| --- | --- |
| `hovercard.HoverCard` | `hovercard.OpenDelay(ms)` (default 700), `hovercard.CloseDelay(ms)` (default 300), `hovercard.DefaultOpen` |
| `hovercard.Trigger` | `lib.AsChild` to render the child element as the trigger instead of an `<a>` |
| `hovercard.Content` | side, alignment, `hovercard.SideOffset(px)` (default 4), `hovercard.AlignOffset(px)`, `hovercard.AvoidCollisions(bool)`, `hovercard.CollisionPadding(px)`, `hovercard.Sticky...`, `hovercard.HideWhenDetached(bool)` |

Other children are HTML attributes (`h.Class`, `h.ID`, ...) and content. The
behavior follows [Radix UI's Hover Card](https://www.radix-ui.com/docs/primitives/components/hover-card#api-reference).
