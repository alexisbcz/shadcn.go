## Installation

```bash
go get github.com/alexisbcz/components
go mod tidy
```

The component's behavior is a JavaScript module served by the runtime. Serve
the runtime and load it once per page, as in the
[components README](https://github.com/alexisbcz/components#use):

```go showLineNumbers
http.Handle(runtime.Prefix, runtime.Handler())
// In <head>:
runtime.Scripts(r)
```

## Usage

```go showLineNumbers
import (
	"github.com/alexisbcz/components/ui/checkbox"
	h "github.com/alexisbcz/libhtml"
)
```

```go showLineNumbers
checkbox.Checkbox(h.ID("terms"))
```

## Checked State

Pass `checkbox.Checked(true)` (or `checkbox.Indeterminate`) to set the initial
state. The state then lives in the browser: the checkbox's `data-state` is
`checked`, `unchecked` or `indeterminate`, and inside a `<form>` its hidden
input submits `checkbox.Value` (default `"on"`) under `checkbox.Name`.

```go showLineNumbers
checkbox.Checkbox(h.ID("terms"), checkbox.Name("terms"), checkbox.Checked(true))
```

To react to changes, listen for the `shadcn:checked-change` event, dispatched
before every change. Its `detail.checked` is `true`, `false` or
`"indeterminate"`. Call `preventDefault()` to cancel the change.

```js showLineNumbers
document.querySelector("#terms").addEventListener("shadcn:checked-change", (e) => {
  console.log(e.detail.checked)
})
```

## API Reference

| Function | Options |
| --- | --- |
| `checkbox.Checkbox` | `checkbox.Checked(bool)` (initial state), `checkbox.Indeterminate`, `checkbox.Name`, `checkbox.Value` (default `"on"`), `checkbox.Required(bool)`, `checkbox.Disabled(bool)`, `checkbox.Form(id)` |

The same options exist as builder methods (`checkbox.Checkbox().Checked(true)`).
The attributes `h.Name`, `h.Value`, `h.Required()`, `h.Disabled()` and
`h.FormAttr` are equivalent to the typed options. Other children are HTML
attributes (`h.Class`, `h.ID`, ...).

A click (or Space) toggles the checkbox, and an indeterminate checkbox becomes
checked. The cancelable `shadcn:checked-change` event is dispatched before
every change. The behavior follows
[Radix UI's Checkbox](https://www.radix-ui.com/docs/primitives/components/checkbox#api-reference).
