## Installation

```bash
go get github.com/alexisbcz/components
go mod tidy
```

## Usage

```go showLineNumbers
import (
	"github.com/alexisbcz/components/ui/textarea"
	h "github.com/alexisbcz/libhtml"
)
```

```go showLineNumbers
textarea.Textarea(h.Placeholder("Type your message here."))
```

## Field

Use `field.Field`, `field.Label`, and `field.Description` to create a textarea with a label and description.

## Disabled

Pass `h.Disabled()` to disable the textarea. To style the disabled state, add the `data-disabled` attribute to the `field.Field` component.

<ComponentPreview
  styleName="radix-nova"
  name="textarea-disabled"
  previewClassName="*:max-w-xs"
/>

## Invalid

Pass `h.Aria("invalid", "true")` to mark the textarea as invalid. To style the invalid state, add the `data-invalid` attribute to the `field.Field` component.

## API Reference

| Function | Options |
| --- | --- |
| `textarea.Textarea` | HTML attributes (`h.Name`, `h.Placeholder`, `h.Disabled()`, `h.Aria("invalid", "true")`, `h.Class`, ...) and content |

The textarea grows with its content (`field-sizing: content`).
