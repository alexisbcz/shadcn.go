## Installation

```bash
go get github.com/alexisbcz/components
go mod tidy
```

## Usage

```go showLineNumbers
import (
	"github.com/alexisbcz/components/ui/button"
	buttongroup "github.com/alexisbcz/components/ui/button-group"
	h "github.com/alexisbcz/libhtml"
)
```

```go showLineNumbers
buttongroup.ButtonGroup(
	button.Button("Button 1"),
	button.Button("Button 2"),
)
```

## Composition

Use the following composition to build a `buttongroup.ButtonGroup`:

```text
buttongroup.ButtonGroup
├── button.Button or input.Input
├── buttongroup.Separator
└── buttongroup.Text
```

## Accessibility

- `buttongroup.ButtonGroup` has the `role` attribute set to `group`.
- Use <Kbd>Tab</Kbd> to navigate between the buttons in the group.
- Use `aria-label` or `aria-labelledby` to label the button group.

```go showLineNumbers
buttongroup.ButtonGroup(h.Aria("label", "Button group"),
	button.Button("Button 1"),
	button.Button("Button 2"),
)
```

## ButtonGroup vs ToggleGroup

- Use `buttongroup.ButtonGroup` when you want to group buttons that perform an action.
- Use `togglegroup.ToggleGroup` when you want to group buttons that toggle a state.

`buttongroup.Separator` visually divides buttons within a group.

## API Reference

| Function | Options |
| --- | --- |
| `buttongroup.ButtonGroup` | `buttongroup.Horizontal` (default), `buttongroup.Vertical` |
| `buttongroup.Separator` | `buttongroup.Vertical` (default), `buttongroup.Horizontal` (a `separator.Orientation` is accepted too) |
| `buttongroup.Text` | `lib.AsChild` to render the child element as the text instead of a `<div>` |

Other children are HTML attributes (`h.Class`, `h.ID`, ...) and content.

Nest multiple button groups to create complex layouts with spacing. See the [nested](#nested) example for more details.

```go showLineNumbers
buttongroup.ButtonGroup(
	buttongroup.ButtonGroup(button.Button("Button 1")),
	buttongroup.ButtonGroup(button.Button("Button 2")),
)
```

Use `buttongroup.Text` to display text within a button group, and
`lib.AsChild` to render another element as the text, for example a label.

```go showLineNumbers
import (
	"github.com/alexisbcz/components/lib"
	buttongroup "github.com/alexisbcz/components/ui/button-group"
	"github.com/alexisbcz/components/ui/input"
	"github.com/alexisbcz/components/ui/label"
	h "github.com/alexisbcz/libhtml"
)

buttongroup.ButtonGroup(
	buttongroup.Text(lib.AsChild,
		label.Label(h.For("name"), "Text"),
	),
	input.Input(h.ID("name"), h.Placeholder("Type something here...")),
)
```
