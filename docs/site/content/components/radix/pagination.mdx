## Installation

```bash
go get github.com/alexisbcz/components
go mod tidy
```

## Usage

```go showLineNumbers
import (
	"github.com/alexisbcz/components/ui/pagination"
	h "github.com/alexisbcz/libhtml"
)
```

```go showLineNumbers
pagination.Pagination(
	pagination.Content(
		pagination.Item(pagination.Previous(h.Href("#"))),
		pagination.Item(pagination.Link(h.Href("#"), "1")),
		pagination.Item(pagination.Link(h.Href("#"), pagination.IsActive, "2")),
		pagination.Item(pagination.Link(h.Href("#"), "3")),
		pagination.Item(pagination.Ellipsis()),
		pagination.Item(pagination.Next(h.Href("#"))),
	),
)
```

## Composition

Use the following composition to build a `Pagination`:

```text
pagination.Pagination
└── pagination.Content
    ├── pagination.Item
    │   └── pagination.Previous
    ├── pagination.Item
    │   └── pagination.Link
    ├── pagination.Item
    │   └── pagination.Ellipsis
    └── pagination.Item
        └── pagination.Next
```

## API Reference

| Function | Options |
| --- | --- |
| `pagination.Pagination` | renders the `<nav>` |
| `pagination.Content` | renders the `<ul>` of items |
| `pagination.Item` | renders one `<li>` |
| `pagination.Link` | `pagination.IsActive` for the current page, a `button.Size` (default `button.SizeIcon`) |
| `pagination.Previous`, `pagination.Next` | `pagination.Text("...")` to replace the label (`"Previous"`, `"Next"`) |
| `pagination.Ellipsis` | |

Links render an `<a>`: pass the page URL with `h.Href`. Other children are HTML
attributes (`h.Class`, `h.ID`, ...) and content.
