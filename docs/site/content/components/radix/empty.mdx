## Installation

```bash
go get github.com/alexisbcz/components
go mod tidy
```

## Usage

```go
import (
	"github.com/alexisbcz/components/ui/empty"
	h "github.com/alexisbcz/libhtml"
)
```

```go
empty.Empty(
	empty.Header(
		empty.Media(empty.MediaIcon, lucide.FolderCode()),
		empty.Title("No data"),
		empty.Description("No data found"),
	),
	empty.Content(
		button.Button("Add data"),
	),
)
```

## Composition

Use the following composition to build an `Empty` state:

```text
empty.Empty
├── empty.Header
│   ├── empty.Media
│   ├── empty.Title
│   └── empty.Description
└── empty.Content
```

## API Reference

| Function | Options |
| --- | --- |
| `empty.Empty` | |
| `empty.Header` | |
| `empty.Media` | `empty.MediaDefault` (default), `empty.MediaIcon` |
| `empty.Title` | |
| `empty.Description` | |
| `empty.Content` | |

Other children are HTML attributes (`h.Class`, `h.ID`, ...) and content.
`empty.MediaVariants(variant, className...)` returns the classes of
`empty.Media` for a variant.

### Empty

The main component of the empty state. Wraps `empty.Header` and `empty.Content`.

```go
empty.Empty(
	empty.Header(),
	empty.Content(),
)
```

### Header

`empty.Header` wraps the empty media, title, and description.

```go
empty.Header(
	empty.Media(),
	empty.Title(),
	empty.Description(),
)
```

### Media

Use `empty.Media` to display the media of the empty state such as an icon or an image. You can also use it to display other components such as an avatar.

```go
empty.Media(empty.MediaIcon,
	lucide.FolderCode(),
)
```

```go
empty.Media(
	avatar.Avatar(
		avatar.Image(h.Src("..."), h.Alt("@shadcn")),
		avatar.Fallback("CN"),
	),
)
```

### Title

Use `empty.Title` to display the title of the empty state.

```go
empty.Title("No data")
```

### Description

Use `empty.Description` to display the description of the empty state.

```go
empty.Description("You do not have any notifications.")
```

### Content

Use `empty.Content` to display the content of the empty state such as a button, input or a link.

```go
empty.Content(
	button.Button("Add Project"),
)
```
