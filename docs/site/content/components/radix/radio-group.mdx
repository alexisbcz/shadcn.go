## Installation

```bash
go get github.com/alexisbcz/components
go mod tidy
```

The component's behavior is a JavaScript module served by the runtime. Serve
the runtime and load it once per page, as in the
[components README](https://github.com/alexisbcz/components#use):

```go showLineNumbers
http.Handle(runtime.Prefix, runtime.Handler())
// In <head>:
runtime.Scripts(r)
```

## Usage

```go showLineNumbers
import (
	"github.com/alexisbcz/components/ui/label"
	radiogroup "github.com/alexisbcz/components/ui/radio-group"
	h "github.com/alexisbcz/libhtml"
)
```

```go showLineNumbers
radiogroup.RadioGroup(radiogroup.Value("option-one"),
	h.Div(h.Class("flex items-center gap-3"),
		radiogroup.Item(radiogroup.Value("option-one"), h.ID("option-one")),
		label.Label(h.For("option-one"), "Option One"),
	),
	h.Div(h.Class("flex items-center gap-3"),
		radiogroup.Item(radiogroup.Value("option-two"), h.ID("option-two")),
		label.Label(h.For("option-two"), "Option Two"),
	),
)
```

## Composition

Use the following composition to build a `RadioGroup`:

```text
radiogroup.RadioGroup
├── radiogroup.Item
└── radiogroup.Item
```

## API Reference

| Function | Options |
| --- | --- |
| `radiogroup.RadioGroup` | `radiogroup.Value("...")` for the initially checked item, `radiogroup.Name("...")`, `radiogroup.Required(true)`, `radiogroup.Disabled(true)`, `radiogroup.OrientationHorizontal` or `OrientationVertical`, `radiogroup.Loop(bool)` (default true) |
| `radiogroup.Item` | `radiogroup.Value("...")` (default `"on"`), `h.Disabled()` |

Items may sit anywhere under the group. Other children are HTML attributes
(`h.ID`, `h.Class`, ...) and content. Inside a `<form>`, each item renders a
hidden radio input, so the value submits with the form.

Before every change, the group dispatches a cancelable `shadcn:value-change`
event with `detail: { value }`. Cancel it to keep the current value.

```js showLineNumbers
group.addEventListener("shadcn:value-change", (e) => {
  console.log(e.detail.value)
})
```

The behavior follows [Radix UI's Radio Group](https://www.radix-ui.com/docs/primitives/components/radio-group#api-reference).
