## Installation

```bash
go get github.com/alexisbcz/components
go mod tidy
```

## Usage

```go showLineNumbers
import (
	"github.com/alexisbcz/components/ui/alert"
	"github.com/alexisbcz/components/ui/button"
	"github.com/alexisbcz/icons/lucide"
	h "github.com/alexisbcz/libhtml"
)
```

```go showLineNumbers
alert.Alert(
	lucide.Info(),
	alert.Title("Heads up!"),
	alert.Description("You can add components and dependencies to your app using the cli."),
	alert.Action(
		button.Button(button.VariantOutline, "Enable"),
	),
)
```

## Composition

Use the following composition to build an `Alert`:

```text
alert.Alert
├── Icon (lucide.Info, ...)
├── alert.Title
├── alert.Description
└── alert.Action
```

## API Reference

| Function | Options |
| --- | --- |
| `alert.Alert` | `alert.VariantDefault` (default) or `alert.VariantDestructive` |
| `alert.Title` | none |
| `alert.Description` | none |
| `alert.Action` | none; positioned in the top-right corner of the alert |

Other children are HTML attributes (`h.Class`, `h.ID`, ...) and content.
`alert.Variants(variant, classes...)` returns the classes of an alert, for
use on another element.
