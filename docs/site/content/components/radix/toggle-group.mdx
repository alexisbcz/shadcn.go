## Installation

```bash
go get github.com/alexisbcz/components
go mod tidy
```

The component's behavior is a JavaScript module served by the runtime. Serve
the runtime and load it once per page, as in the
[components README](https://github.com/alexisbcz/components#use):

```go showLineNumbers
http.Handle(runtime.Prefix, runtime.Handler())
// In <head>:
runtime.Scripts(r)
```

## Usage

```go showLineNumbers
import (
	togglegroup "github.com/alexisbcz/components/ui/toggle-group"
	h "github.com/alexisbcz/libhtml"
)
```

```go showLineNumbers
togglegroup.ToggleGroup(togglegroup.TypeSingle,
	togglegroup.Item(togglegroup.Value("a"), "A"),
	togglegroup.Item(togglegroup.Value("b"), "B"),
	togglegroup.Item(togglegroup.Value("c"), "C"),
)
```

## Composition

Use the following composition to build a `ToggleGroup`:

```text
togglegroup.ToggleGroup
├── togglegroup.Item
└── togglegroup.Item
```

## API Reference

| Function | Options |
| --- | --- |
| `togglegroup.ToggleGroup` | `togglegroup.TypeSingle` or `togglegroup.TypeMultiple` (required), a variant, a size, `togglegroup.Spacing(n)`, `togglegroup.Value("...")` for the initially pressed items (repeat it with `TypeMultiple`), `togglegroup.Disabled(true)`, `togglegroup.OrientationHorizontal` or `OrientationVertical`, `togglegroup.Loop(bool)` (default true), `togglegroup.RovingFocus(bool)` (default true), `togglegroup.Required(true)` to keep one item pressed in a single group |
| `togglegroup.Item` | `togglegroup.Value("...")`, a variant, a size, `h.Disabled()` |

Variants are `togglegroup.VariantDefault` and `VariantOutline`; sizes are
`togglegroup.SizeDefault`, `SizeSm` and `SizeLg`. The group's variant and size
win over the item's. Other children are HTML attributes (`h.Class`, `h.Aria`,
...) and content.

Before every change, the group dispatches a cancelable `shadcn:value-change`
event with `detail: { item, pressed, pressedItems }` (the item elements;
`pressedItems` is the state after the change). Cancel it to keep the current
state. After the change, when the items' `data-state` is up to date, it
dispatches `shadcn:value-changed` with the same detail.

```js showLineNumbers
group.addEventListener("shadcn:value-changed", (e) => {
  console.log(e.detail.item, e.detail.pressed, e.detail.pressedItems)
})
```

In a single group, pressing the pressed item releases it, as in Radix, which
leaves no item pressed. Pass `togglegroup.Required(true)` to keep one item
pressed.

The behavior follows [Radix UI's Toggle Group](https://www.radix-ui.com/docs/primitives/components/toggle-group#api-reference).
