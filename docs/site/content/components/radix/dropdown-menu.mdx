## Installation

```bash
go get github.com/alexisbcz/components
go mod tidy
```

The component's behavior is a JavaScript module served by the runtime. Serve
the runtime and load it once per page, as in the
[components README](https://github.com/alexisbcz/components#use):

```go showLineNumbers
http.Handle(runtime.Prefix, runtime.Handler())
// In <head>:
runtime.Scripts(r)
```

## Usage

```go showLineNumbers
import (
	"github.com/alexisbcz/components/lib"
	"github.com/alexisbcz/components/ui/button"
	dropdownmenu "github.com/alexisbcz/components/ui/dropdown-menu"
	h "github.com/alexisbcz/libhtml"
)
```

```go showLineNumbers
dropdownmenu.DropdownMenu(
	dropdownmenu.Trigger(lib.AsChild, button.Button(button.VariantOutline, "Open")),
	dropdownmenu.Content(
		dropdownmenu.Group(
			dropdownmenu.Label("My Account"),
			dropdownmenu.Item("Profile"),
			dropdownmenu.Item("Billing"),
		),
		dropdownmenu.Separator(),
		dropdownmenu.Group(
			dropdownmenu.Item("Team"),
			dropdownmenu.Item("Subscription"),
		),
	),
)
```

## Composition

Use the following composition to build a `DropdownMenu`:

```text
dropdownmenu.DropdownMenu
├── dropdownmenu.Trigger
└── dropdownmenu.Content
    ├── dropdownmenu.Group
    │   ├── dropdownmenu.Label
    │   ├── dropdownmenu.Item
    │   └── dropdownmenu.Item
    ├── dropdownmenu.Separator
    ├── dropdownmenu.Group
    │   ├── dropdownmenu.Label
    │   ├── dropdownmenu.CheckboxItem
    │   └── dropdownmenu.CheckboxItem
    ├── dropdownmenu.Separator
    ├── dropdownmenu.Group
    │   ├── dropdownmenu.Label
    │   └── dropdownmenu.RadioGroup
    │       ├── dropdownmenu.RadioItem
    │       └── dropdownmenu.RadioItem
    └── dropdownmenu.Sub
        ├── dropdownmenu.SubTrigger
        └── dropdownmenu.SubContent
            └── dropdownmenu.Group
                ├── dropdownmenu.Label
                ├── dropdownmenu.Item
                └── dropdownmenu.Item
```

## API Reference

| Function | Options |
| --- | --- |
| `dropdownmenu.DropdownMenu` | `dropdownmenu.Modal(bool)` (default true), `dropdownmenu.DefaultOpen`, `dropdownmenu.Dir("rtl")` |
| `dropdownmenu.Trigger` | `dropdownmenu.Disabled(true)`, `lib.AsChild` |
| `dropdownmenu.Content`, `dropdownmenu.SubContent` | side (`dropdownmenu.SideTop`, `SideRight`, `SideBottom`, `SideLeft`), alignment (`dropdownmenu.AlignStart`, `AlignCenter`, `AlignEnd`), `dropdownmenu.SideOffset(px)` (default 4), `dropdownmenu.AlignOffset(px)`, `dropdownmenu.AvoidCollisions(bool)`, `dropdownmenu.CollisionPadding(px)`, `dropdownmenu.Sticky("always")`, `dropdownmenu.HideWhenDetached(bool)`, `dropdownmenu.Loop(bool)` |
| `dropdownmenu.Item` | `dropdownmenu.VariantDestructive`, `dropdownmenu.Inset(true)`, `dropdownmenu.Disabled(true)`, `dropdownmenu.TextValue(s)` |
| `dropdownmenu.CheckboxItem` | `dropdownmenu.Checked(bool)`, `dropdownmenu.Indeterminate`, `dropdownmenu.Controlled`, `dropdownmenu.Disabled(true)` |
| `dropdownmenu.RadioGroup` | `dropdownmenu.Value(v)`, `dropdownmenu.Controlled` |
| `dropdownmenu.RadioItem` | `dropdownmenu.Value(v)`, `dropdownmenu.Disabled(true)` |
| `dropdownmenu.Sub` | `dropdownmenu.SubDefaultOpen(true)` |
| `dropdownmenu.SubTrigger`, `dropdownmenu.Label` | `dropdownmenu.Inset(true)` |
| `dropdownmenu.Group`, `dropdownmenu.Separator`, `dropdownmenu.Shortcut`, `dropdownmenu.Portal` | |

Other children are HTML attributes (`h.Class`, `h.ID`, ...) and content.

The menu dispatches a cancelable `shadcn:open-change` event (`detail.open`)
when it opens or closes. Checkbox items and radio groups keep their state in
the page. `dropdownmenu.Controlled` leaves the state to your scripts. The menu
dispatches bubbling, cancelable events on the live elements: `shadcn:select`
on an item (cancel it to keep the menu open), `shadcn:checked-change` on a
checkbox item (`detail.checked`), `shadcn:value-change` on a radio group
(`detail.value`).

```js showLineNumbers
document.addEventListener("shadcn:checked-change", (e) => {
  console.log(e.detail.checked)
})
```

The behavior follows [Radix UI's Dropdown Menu](https://www.radix-ui.com/docs/primitives/components/dropdown-menu#api-reference).
