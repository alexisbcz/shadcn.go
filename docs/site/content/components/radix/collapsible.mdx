## Installation

```bash
go get github.com/alexisbcz/components
go mod tidy
```

The component's behavior is a JavaScript module served by the runtime. Serve
the runtime and load it once per page, as in the
[components README](https://github.com/alexisbcz/components#use):

```go showLineNumbers
http.Handle(runtime.Prefix, runtime.Handler())
// In <head>:
runtime.Scripts(r)
```

## Usage

```go showLineNumbers
import (
	"github.com/alexisbcz/components/ui/collapsible"
	h "github.com/alexisbcz/libhtml"
)
```

```go showLineNumbers
collapsible.Collapsible(
	collapsible.Trigger("Can I use this in my project?"),
	collapsible.Content(
		"Yes. Free to use for personal and commercial projects. No attribution required.",
	),
)
```

## Composition

Use the following composition to build a `collapsible.Collapsible`:

```text
collapsible.Collapsible
├── collapsible.Trigger
└── collapsible.Content
```

## Open State

Pass `collapsible.Open(true)` to start open. The state then lives in the
browser: before every change, the root dispatches a cancelable
`shadcn:open-change` event with `detail.open` set to the next state. Call
`preventDefault()` to keep the current state.

```go showLineNumbers
collapsible.Collapsible(collapsible.Open(true), h.ID("faq"),
	collapsible.Trigger("Toggle"),
	collapsible.Content("Content"),
)
```

```js showLineNumbers
document.getElementById("faq").addEventListener("shadcn:open-change", (event) => {
  console.log(event.detail.open)
})
```

## API Reference

| Function | Options |
| --- | --- |
| `collapsible.Collapsible` | `collapsible.Open(bool)` (the initial state, default false), `collapsible.Disabled(bool)` |
| `collapsible.Trigger` | `lib.AsChild` to render the child element as the trigger instead of a `<button>` |
| `collapsible.Content` | none; mounted only while open |

Other children are HTML attributes (`h.Class`, `h.ID`, ...) and content. The
content's size is exposed as `--radix-collapsible-content-height` and
`--radix-collapsible-content-width` for animations. See the
[Radix UI](https://www.radix-ui.com/docs/primitives/components/collapsible#api-reference)
documentation for more information.
