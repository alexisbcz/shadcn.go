Introducing **Charts**. A collection of chart components that you can copy and paste into your apps.

Charts are designed to look great out of the box. They work well with the other components and are fully customizable to fit your project.

[Browse the Charts Library](/charts).

## Component

The charts are rendered in the browser by `chart.js`, a port of [Recharts](https://recharts.org/) 3.8.0 that renders the same SVG Recharts renders.

We designed the `chart` component with composition in mind. **You describe your chart with the Recharts element names and props (`chart.BarChart`, `chart.Bar`, `chart.XAxis`, ...) and only bring in shadcn parts, such as `chart.TooltipContent`, when and where you need them**.

```go showLineNumbers
import (
	"github.com/alexisbcz/components/ui/chart"
	h "github.com/alexisbcz/libhtml"
)

func MyChart() h.Node {
	return chart.Container(chartConfig,
		chart.BarChart(chart.Data(data),
			chart.Bar(chart.DataKey("value")),
			chart.Tooltip(chart.TooltipContent()),
		),
	)
}
```

Props use Recharts' names: `chart.DataKey("month")` is `dataKey="month"`, and `chart.P("key", value)` sets a prop that has no helper. Function props, such as tick formatters and custom shapes, are named functions of the runtime: `chart.Slice`, `chart.ConfigLabel`, `chart.DateFormat`, ...

## Chart Config

The chart config is where you define the labels, icons and colors for a chart.

It is intentionally decoupled from chart data.

This allows you to share config and color tokens between charts. It can also work independently for cases where your data or color tokens live remotely or in a different format.

```go showLineNumbers
import (
	"github.com/alexisbcz/components/ui/chart"
	"github.com/alexisbcz/icons/lucide"
)

var chartConfig = chart.Config{
	{
		Key:   "desktop",
		Label: "Desktop",
		Icon:  lucide.Monitor,
		// A color like 'hsl(220, 98%, 61%)' or 'var(--color-name)'
		Color: "#2563eb",
		// OR a theme with light and dark colors
		// Theme: &chart.Theme{Light: "#2563eb", Dark: "#dc2626"},
	},
}
```

`chart.Config` is a slice, so the items keep their declaration order.

## Theming

Charts have built-in support for theming. You can use css variables (recommended) or color values in any color format, such as hex, hsl or oklch.

### hex, hsl or oklch

You can also define your colors directly in the chart config. Use the color format you prefer.

```go showLineNumbers
var chartConfig = chart.Config{
	{Key: "desktop", Label: "Desktop", Color: "#2563eb"},
	{Key: "mobile", Label: "Mobile", Color: "hsl(220, 98%, 61%)"},
	{Key: "tablet", Label: "Tablet", Color: "oklch(0.5 0.2 240)"},
	{Key: "laptop", Label: "Laptop", Color: "var(--chart-2)"},
}
```

### Using Colors

To use the theme colors in your chart, reference the colors using the format `var(--color-KEY)`.

#### Components

```go
chart.Bar(chart.DataKey("desktop"), chart.Fill("var(--color-desktop)"))
```

#### Chart Data

```go showLineNumbers
var chartData = []chart.Row{
	{"browser": "chrome", "visitors": 275, "fill": "var(--color-chrome)"},
	{"browser": "safari", "visitors": 200, "fill": "var(--color-safari)"},
}
```

#### Tailwind

```go
chart.LabelList(chart.ClassName("fill-(--color-desktop)"))
```

## Tooltip

A chart tooltip contains a label, name, indicator and value. You can use a combination of these to customize your tooltip.

<ComponentPreview styleName="radix-nova" name="chart-tooltip" hideCode />

You can turn off any of these using `chart.HideLabel()` and `chart.HideIndicator()`, and customize the indicator style using `chart.Indicator`.

Use `chart.LabelKey` and `chart.NameKey` to use a custom key for the tooltip label and name.

Chart comes with `chart.Tooltip` and `chart.TooltipContent`. You can use these two to add custom tooltips to your chart.

```go
chart.Tooltip(chart.TooltipContent())
```

### Options

Pass the following options to `chart.TooltipContent` to customize the tooltip.

| Option | Description |
| :-- | :-- |
| `chart.LabelKey(key)` | The config or data key to use for the label. |
| `chart.NameKey(key)` | The config or data key to use for the name. |
| `chart.Indicator(style)` | The indicator style for the tooltip: `"dot"` (default), `"line"` or `"dashed"`. |
| `chart.HideLabel()` | Hides the label. |
| `chart.HideIndicator()` | Hides the indicator. |
| `chart.LabelFormatter(fn)` | Formats the label with a runtime function. |
| `chart.ClassName(c)`, `chart.LabelClassName(c)` | Classes for the tooltip and its label. |

### Colors

Colors are automatically referenced from the chart config.

### Custom

To use a custom key for tooltip label and names, use `chart.LabelKey` and `chart.NameKey`.

```go showLineNumbers
var chartData = []chart.Row{
	{"browser": "chrome", "visitors": 187, "fill": "var(--color-chrome)"},
	{"browser": "safari", "visitors": 200, "fill": "var(--color-safari)"},
}

var chartConfig = chart.Config{
	{Key: "visitors", Label: "Total Visitors"},
	{Key: "chrome", Label: "Chrome", Color: "var(--chart-1)"},
	{Key: "safari", Label: "Safari", Color: "var(--chart-2)"},
}
```

```go
chart.Tooltip(chart.TooltipContent(chart.LabelKey("visitors"), chart.NameKey("browser")))
```

This will use `Total Visitors` for label and `Chrome` and `Safari` for the tooltip names.

## Accessibility

You can turn on `chart.AccessibilityLayer()` to add an accessible layer to your chart.

This option adds keyboard access and screen reader support to your charts.

```go
chart.LineChart(chart.AccessibilityLayer())
```

## API Reference

| Function | Options |
| --- | --- |
| `chart.Container` | the `chart.Config` first, then the chart root, `chart.ID(id)`, `chart.Nonce(nonce)` (the CSP nonce of its `<style>`), `chart.InitialDimension{Width, Height}` (default 320x200) |
| `chart.AreaChart`, `chart.BarChart`, `chart.LineChart`, `chart.ComposedChart`, `chart.PieChart`, `chart.RadarChart` | `chart.Data(rows)`, `chart.Margin{...}`, `chart.Layout`, `chart.AccessibilityLayer()`, ... and the elements below |
| `chart.CartesianGrid`, `chart.XAxis`, `chart.YAxis`, `chart.Area`, `chart.Bar`, `chart.Line`, `chart.Pie`, `chart.LabelList`, `chart.Cell`, `chart.Label` | Recharts props: `chart.DataKey`, `chart.Fill`, `chart.Stroke`, `chart.Radius`, `chart.TickFormatter`, ..., or `chart.P(key, value)` |
| `chart.Tooltip` | `chart.TooltipContent(...)`, `chart.Cursor(v)` |
| `chart.Legend` | `chart.LegendContent(...)`, `chart.VerticalAlign(v)` |
| `chart.TooltipContent` | see [Tooltip](#tooltip) |
| `chart.LegendContent` | `chart.NameKey(key)`, `chart.HideIcon()`, `chart.VerticalAlign(v)`, `chart.ClassName(c)` |

Other children of `chart.Container` are HTML attributes (`h.Class`, `h.ID`, ...).
Elements without a helper are built with `chart.El(name, ...)`. The container's
`<style>` sets the `--color-KEY` variables of the config.
