The `Attachment` component displays a file or image attachment, its media, name, and metadata, with optional actions and upload state. Use it for files and images in chat composers, message threads, and upload lists.

## Installation

```bash
go get github.com/alexisbcz/components
go mod tidy
```

## Usage

```go
import (
	"github.com/alexisbcz/components/ui/attachment"
	"github.com/alexisbcz/icons/lucide"
	h "github.com/alexisbcz/libhtml"
)
```

```go
attachment.Attachment(
	attachment.Media(lucide.FileText()),
	attachment.Content(
		attachment.Title("sales-dashboard.pdf"),
		attachment.Description("PDF · 2.4 MB"),
	),
	attachment.Actions(
		attachment.Action(h.Aria("label", "Remove sales-dashboard.pdf"),
			lucide.X(),
		),
	),
)
```

## Composition

Use the following composition to build an attachment:

```text
attachment.Attachment
├── attachment.Media
├── attachment.Content
│   ├── attachment.Title
│   └── attachment.Description
├── attachment.Actions
│   └── attachment.Action
└── attachment.Trigger
```

Use `attachment.Group` to lay out multiple attachments in a scrollable row:

```text
attachment.Group
├── attachment.Attachment
└── attachment.Attachment
```

## Features

- Icon and image media through `attachment.Media`
- Upload states: `attachment.StateIdle`, `StateUploading`, `StateProcessing`, `StateError`, and `StateDone` with built-in styling and a shimmer while in progress
- Three sizes and horizontal or vertical orientation
- A full-card `attachment.Trigger` that opens a link or dialog while the actions stay independently clickable
- Scrollable, snapping `attachment.Group` with an edge fade
- Customizable styling through `h.Class(...)` on every part

## Image

Pass `attachment.MediaImage` to `attachment.Media` and render an `h.Img` inside it. Pass `attachment.Vertical` to `attachment.Attachment` to stack the media above the content.

```go showLineNumbers
attachment.Attachment(attachment.Vertical,
	attachment.Media(attachment.MediaImage, h.Img(h.Src("/workspace.png"), h.Alt("Workspace"))),
	attachment.Content(
		attachment.Title("workspace.png"),
		attachment.Description("PNG · 820 KB"),
	),
)
```

## States

Pass a state to `attachment.Attachment` to reflect the upload lifecycle. `attachment.StateUploading` and `attachment.StateProcessing` shimmer the title, and `attachment.StateError` switches to a destructive treatment.

```go showLineNumbers
attachment.Attachment(attachment.StateUploading,
	attachment.Media(spinner.Spinner()),
	attachment.Content(
		attachment.Title("report.pdf"),
		attachment.Description("Uploading..."),
	),
)
```

## Trigger

Add an `attachment.Trigger` to make the whole card open a link or dialog. It fills the card behind the actions, so the actions stay clickable.

```go showLineNumbers
dialog.Dialog(
	attachment.Attachment(
		// media, content, actions
		dialog.Trigger(lib.AsChild,
			attachment.Trigger(h.Aria("label", "Preview research-summary.pdf")),
		),
	),
	dialog.Content( /* ... */ ),
)
```

## Accessibility

`attachment.Action` renders a `button.Button`, and `attachment.Trigger` renders a real `<button>` (or your element via `lib.AsChild`). Follow the guidance below so both are operable and announced.

### Label icon-only actions

`attachment.Action` is usually icon-only, so give each one an `aria-label` describing the action and its target.

```go showLineNumbers
attachment.Action(h.Aria("label", "Remove sales-dashboard.pdf"),
	lucide.X(),
)
```

### Label the trigger

`attachment.Trigger` covers the card with no text of its own, so give it an `aria-label` for what activating it does.

```go showLineNumbers
attachment.Trigger(lib.AsChild,
	h.A(h.Href(url), h.Target("_blank"), h.Rel("noreferrer"),
		h.Aria("label", "Open workspace.png"),
	),
)
```

The trigger sits behind the actions in the stacking order, so an `attachment.Action` and the `attachment.Trigger` never trap each other — both remain separately focusable and clickable.

### Keyboard scrolling

An `attachment.Group` scrolls horizontally. When its attachments are interactive: a trigger or actions, keyboard users reach off-screen items by tabbing to them. For a row of presentational attachments, make the group itself focusable and scrollable by adding `h.TabIndex(0)`, `h.Role("group")`, and an `aria-label`.

### Meaning beyond color

The `attachment.StateError` state uses a destructive color. Keep the failure reason in `attachment.Description` so the state is not conveyed by color alone.

## API Reference

| Function | Options |
| --- | --- |
| `attachment.Attachment` | a state (`attachment.StateIdle`, `StateUploading`, `StateProcessing`, `StateError`, `StateDone` (default)), a size (`attachment.SizeDefault` (default), `SizeSm`, `SizeXs`), an orientation (`attachment.Horizontal` (default), `attachment.Vertical`) |
| `attachment.Media` | `attachment.MediaIcon` (default) or `attachment.MediaImage` for an `<img>` |
| `attachment.Content` | wraps the title and description |
| `attachment.Title` | the attachment name. Shimmers while uploading or processing |
| `attachment.Description` | secondary metadata such as the file type, size, or upload status |
| `attachment.Actions` | a container for actions, aligned to the end of the attachment |
| `attachment.Action` | a [`button.Button`](/docs/components/radix/button) (ghost, `button.SizeIconXs` by default). A `button.Variant` or `button.Size` overrides the defaults |
| `attachment.Trigger` | a full-card `<button>` overlay. `lib.AsChild` to render the child element (a link) instead |
| `attachment.Group` | lays out attachments in a horizontally scrollable, snapping row |

Other children are HTML attributes (`h.Class`, `h.ID`, ...) and content.
