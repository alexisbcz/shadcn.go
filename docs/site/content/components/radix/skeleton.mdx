## Installation

```bash
go get github.com/alexisbcz/components
go mod tidy
```

## Usage

```go showLineNumbers
import (
	"github.com/alexisbcz/components/ui/skeleton"
	h "github.com/alexisbcz/libhtml"
)
```

```go showLineNumbers
skeleton.Skeleton(h.Class("h-[20px] w-[100px] rounded-full"))
```
