## Installation

```bash
go get github.com/alexisbcz/components
go mod tidy
```

## Usage

```go showLineNumbers
import (
	"github.com/alexisbcz/components/ui/kbd"
)
```

```go showLineNumbers
kbd.Kbd("Ctrl")
```

## Composition

Use the following composition to build `kbd.Kbd` and `kbd.Group`:

```text
kbd.Kbd
kbd.Group
├── kbd.Kbd
└── kbd.Kbd
```

## Group

Use `kbd.Group` to group keyboard keys together.

## API Reference

| Function | Options |
| --- | --- |
| `kbd.Kbd` | none; renders a `<kbd>` key |
| `kbd.Group` | none; renders a `<kbd>` grouping several `kbd.Kbd` |

Children are HTML attributes (`h.Class`, `h.ID`, ...) and content.

```go showLineNumbers
kbd.Group(
	kbd.Kbd("Ctrl"),
	kbd.Kbd("B"),
)
```
