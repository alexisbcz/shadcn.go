`item.Item` is a straightforward flex container that can house nearly any type of content. Use it to display a title, description, and actions. Group it with `item.Group` to create a list of items.

## Installation

```bash
go get github.com/alexisbcz/components
go mod tidy
```

## Usage

```go showLineNumbers
import (
	"github.com/alexisbcz/components/ui/button"
	"github.com/alexisbcz/components/ui/item"
	"github.com/alexisbcz/icons/lucide"
	h "github.com/alexisbcz/libhtml"
)
```

```go showLineNumbers
item.Item(
	item.Media(item.MediaIcon, lucide.Inbox()),
	item.Content(
		item.Title("Title"),
		item.Description("Description"),
	),
	item.Actions(button.Button("Action")),
)
```

## Composition

Use the following composition to build an `item.Item`:

```text
item.Group
└── item.Item
    ├── item.Header
    ├── item.Media
    ├── item.Content
    │   ├── item.Title
    │   └── item.Description
    ├── item.Actions
    └── item.Footer
```

## Item vs Field

Use [Field](/docs/components/radix/field) if you need to display a form input such as a checkbox, input, radio, or select.

If you only need to display content such as a title, description, and actions, use `item.Item`.

## Link

Pass `lib.AsChild` to render the item as a link. The hover and focus states will be applied to the anchor element.

<ComponentPreview styleName="radix-nova" name="item-link" />

```go showLineNumbers
item.Item(lib.AsChild,
	h.A(h.Href("/dashboard"),
		item.Media(item.MediaIcon, lucide.House()),
		item.Content(
			item.Title("Dashboard"),
			item.Description("Overview of your account and activity."),
		),
	),
)
```

## API Reference

| Function | Options |
| --- | --- |
| `item.Item` | `item.VariantDefault` (default), `item.VariantOutline`, `item.VariantMuted`; `item.SizeDefault` (default), `item.SizeSm`, `item.SizeXs`; `lib.AsChild` to render its single element child (e.g. an `<a>`) as the item |
| `item.Group` | Groups related items (`role="list"`). |
| `item.Separator` | A separator between items in a group. Horizontal unless given a `separator.Orientation`. |
| `item.Media` | `item.MediaDefault` (default), `item.MediaIcon`, `item.MediaImage` |
| `item.Content` | Wraps the title and description. |
| `item.Title` | The item's title. |
| `item.Description` | The item's description (a `<p>`, clamped to two lines). |
| `item.Actions` | Container for buttons or other controls. |
| `item.Header` | Spans the item's full width above its content. |
| `item.Footer` | Spans the item's full width below its content. |

Other children are HTML attributes (`h.Class`, `h.ID`, ...) and content.

```go showLineNumbers
item.Group(
	item.Item(item.Content(item.Title("First"))),
	item.Separator(),
	item.Item(item.Content(item.Title("Second"))),
)
```

```go showLineNumbers
item.Media(item.MediaImage,
	h.Img(h.Src("/cover.png"), h.Alt("Cover")),
)
```

```go showLineNumbers
item.Item(
	item.Header("Header"),
	item.Content(item.Title("Title")),
	item.Footer("Footer"),
)
```
