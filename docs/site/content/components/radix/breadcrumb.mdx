## Installation

```bash
go get github.com/alexisbcz/components
go mod tidy
```

## Usage

```go showLineNumbers
import (
	"github.com/alexisbcz/components/ui/breadcrumb"
	h "github.com/alexisbcz/libhtml"
)
```

```go showLineNumbers
breadcrumb.Breadcrumb(
	breadcrumb.List(
		breadcrumb.Item(breadcrumb.Link(h.Href("/"), "Home")),
		breadcrumb.Separator(),
		breadcrumb.Item(breadcrumb.Link(h.Href("/components"), "Components")),
		breadcrumb.Separator(),
		breadcrumb.Item(breadcrumb.Page("Breadcrumb")),
	),
)
```

## Composition

Use the following composition to build a `Breadcrumb`:

```text
breadcrumb.Breadcrumb
└── breadcrumb.List
    ├── breadcrumb.Item
    │   └── breadcrumb.Link
    ├── breadcrumb.Separator
    ├── breadcrumb.Item
    │   └── breadcrumb.Link
    ├── breadcrumb.Separator
    └── breadcrumb.Item
        └── breadcrumb.Page
```

## Custom separator

Pass an icon or other content as children to `breadcrumb.Separator` to create a custom separator.

```go showLineNumbers
breadcrumb.Separator(lucide.Slash())
```

## Dropdown

You can compose `breadcrumb.Item` with a `dropdownmenu.DropdownMenu` to create a dropdown in the breadcrumb.

```go showLineNumbers
breadcrumb.Item(
	dropdownmenu.DropdownMenu(
		dropdownmenu.Trigger(h.Class("flex items-center gap-1"), "Components", lucide.ChevronDown()),
		dropdownmenu.Content(dropdownmenu.AlignStart,
			dropdownmenu.Item("Documentation"),
			dropdownmenu.Item("Themes"),
			dropdownmenu.Item("GitHub"),
		),
	),
)
```

## Collapsed

Use `breadcrumb.Ellipsis` to show a collapsed state when the breadcrumb is too long.

```go showLineNumbers
breadcrumb.Item(breadcrumb.Ellipsis())
```

## Link component

To use your own link element, pass `lib.AsChild` to `breadcrumb.Link`. The link's classes and attributes are merged into the child element.

```go showLineNumbers
breadcrumb.Link(lib.AsChild, h.A(h.Href("/components"), "Components"))
```

## API Reference

| Function | Renders | Options |
| --- | --- | --- |
| `breadcrumb.Breadcrumb` | the root `<nav aria-label="breadcrumb">` | - |
| `breadcrumb.List` | the ordered list of items (`<ol>`) | - |
| `breadcrumb.Item` | one entry of the list (`<li>`) | - |
| `breadcrumb.Link` | a link to an ancestor page (`<a>`) | `lib.AsChild` to render the child element as the link |
| `breadcrumb.Page` | the current page, not clickable (`<span aria-current="page">`) | - |
| `breadcrumb.Separator` | a separator between items; shows a chevron unless given children | - |
| `breadcrumb.Ellipsis` | an ellipsis for collapsed items; always renders its icon and a "More" label, child nodes are ignored | - |

Other children are HTML attributes (`h.Class`, `h.Href`, ...) and content.
