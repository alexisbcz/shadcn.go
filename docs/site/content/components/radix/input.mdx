## Installation

```bash
go get github.com/alexisbcz/components
go mod tidy
```

## Usage

```go showLineNumbers
import (
	"github.com/alexisbcz/components/ui/input"
	h "github.com/alexisbcz/libhtml"
)
```

```go showLineNumbers
input.Input(h.Type("email"), h.Placeholder("Email"))
```
