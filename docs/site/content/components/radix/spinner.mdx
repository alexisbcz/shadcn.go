## Customization

You can replace the default spinner icon with any other icon by writing your own `Spinner` function.

<ComponentPreview styleName="radix-nova" name="spinner-custom" />

```go showLineNumbers
import (
	"github.com/alexisbcz/components/lib"
	"github.com/alexisbcz/icons/lucide"
	h "github.com/alexisbcz/libhtml"
)

func Spinner(class string) h.Node {
	return lucide.Loader(
		h.Role("status"),
		h.Aria("label", "Loading"),
		h.Class(lib.Cn("size-4 animate-spin", class)),
	)
}
```

## Size

Pass a `size-*` utility class with `h.Class` to change the size of the spinner.

## Button

Add a spinner to a button to indicate a loading state. Place `spinner.Spinner(h.Data("icon", "inline-start"))` before the label for a start position, or `spinner.Spinner(h.Data("icon", "inline-end"))` after the label for an end position.

## Badge

## API Reference

| Function | Options |
| --- | --- |
| `spinner.Spinner` | none; renders a spinning `LoaderCircle` icon with `role="status"` and `aria-label="Loading"` |

Children are HTML attributes (`h.Class`, `h.Data`, ...).
