Composition#

Size#

Pass card.SizeSm to card.Card to set the size of the card to small. The small size variant uses smaller spacing.

Small Card
This card uses the small size variant.

The card component supports a size prop that can be set to "sm" for a more compact appearance.

Spacing#

In addition to card.SizeSm, you can use the --card-spacing CSS variable to control the spacing between sections and the inset of card parts.

API Reference#

FunctionOptions
card.Cardcard.SizeDefault (default) or card.SizeSm; the root container
card.Headernone; holds a title, description and optional action
card.Titlenone; the card title
card.Descriptionnone; helper text under the title
card.Actionnone; content in the top-right of the header (for example, a button or a badge)
card.Contentnone; the main card body
card.Footernone; actions and secondary content at the bottom of the card

Other children are HTML attributes (h.Class, h.ID, ...) and content.
